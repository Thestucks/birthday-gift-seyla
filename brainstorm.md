# Brainstorm Web Surprise Ulang Tahun Seyla (Seylala) — 23rd Birthday

## Informasi Inti

- **Nama:** Seyla
- **Panggilan:** Seyla / Seylala
- **Usia:** 23 Tahun (*Blooming into 23*)
- **Tanggal Lahir:** 24 Oktober 2003
- **Tanggal Ulang Tahun ke-23:** 24 Oktober 2026
- **Tema Utama:** Bunga Pink Cute (*Cute Pink Floral Garden Aesthetic*)
- **Format Proyek:** Web surprise ulang tahun digital interaktif
- **Platform Target:** Mobile-first, tetap nyaman dan estetik dibuka di desktop/tablet
- **Teknologi:** React JS + Vite + Tailwind CSS / Modern CSS
- **Struktur Aset:** Folder `assets/` khusus untuk image (foto, dekorasi) dan music (background audio)
- **Target Deploy:** GitHub Pages

---

## Konsep Utama

Web dibuat sebagai kejutan ulang tahun berkonsep **Cute Pink Floral Garden** (*Taman Bunga Pink yang Cantik & Manis*). Suasananya lembut, manis, ceria, dan estetik dengan animasi kelopak bunga pink yang berjatuhan, sparkle, pita, dan kartu ucapan bergaya scrapbook pastel.

Gaya bahasa dibuat hangat, santai, akrab (*bestie vibes*), dengan sedikit humor lucu khas pertemanan yang menyambut usia 23 tahun.

### Kata Kunci Konsep

- Cute Pink Flowers (Tulip, Daisy, Sakura, Peony)
- Soft Pastel Pink & Cream Aesthetic
- Blooming at 23
- Sparkle & Ribbons
- Warm Bestie Vibes
- Playful & Funny Notes
- Scrapbook Photo Album
- Interactive Music & Confetti

## 11. Rencana Deploy GitHub Pages

1. Inisialisasi Vite + React dengan path base `./` atau repository name (`hbd_seylala`).
2. Instal dependensi `gh-pages` atau konfigurasi GitHub Action workflow.
3. Build production (`npm run build`).
4. Push ke GitHub repository dan deploy ke GitHub Pages.
