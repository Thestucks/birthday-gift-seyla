# Folder Aset Musik (Music) Seyla

Letakkan lagu / background music untuk Seyla di folder ini!
Format yang didukung: `.mp3`, `.wav`, `.m4a`

### Rekomendasi Nama File:
- `birthday.mp3` (atau lagu favorit Seyla)

*Catatan: Web ini sudah memiliki audio player interaktif. Jika file `birthday.mp3` belum ada di folder ini, web otomatis memainkan melodi manis Music Box "Happy Birthday" menggunakan Web Audio API, sehingga lagu tetap berbunyi merdu saat tombol Play ditekan!*
